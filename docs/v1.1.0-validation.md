## 盤點與變更

原專案為原生 JavaScript，無根目錄 package.json。核心測試採 Node test runner；瀏覽器測試用 Playwright；Cloudflare 原型另有 Worker、整合、統計及本機 workerd 測試。

- `js/swap-engine.js`：`search(..., {mode:'special', targetShift:'A'|'E'|'N'})` 新增特殊搜尋。單一 D2 必須是自己的休假；對方 D1 必須休假，D2 必須符合指定班別。省略選項或舊的不相關選項維持 B0 一般搜尋。只改匹配條件，共用原有雙方模擬、未知資料排除、連班及破碎班檢查、排序。
- `js/swap-ui.js`：新增選項控制與結果說明；模式變更清空 D2 與結果；特殊搜尋選新 D2 會取消前一日期；身分重設會關閉特殊搜尋。指定班別變更會清除過期結果。預覽接受符合特殊模式資料的跨班交換，並驗證四個交換後班別與休假方向。
- 邊界風險仍保留於 `risks.context`、`warnings` 及影響資料中，排序函式未修改。只在 UI 顯示前濾除 B0 邊界警告，也移除無結果統計中的邊界提示；連班和破碎班警告仍呈現。
- `index.html`：加入預設關閉的特殊搜尋、A/E/N 下拉選單及人工核對對方班表提示，版本標示改為 v1.1.0。
- `tests/baseline/b0-swap-engine.js`：保存直接下載的正式 B0，供差異回歸。
- `tests/special-search.test.cjs`、`tests/special-search-browser.test.cjs`：新增功能與操作驗收。既有核心測試僅改一項標題，說明邊界警告屬內部資料。
